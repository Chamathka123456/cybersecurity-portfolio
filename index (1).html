Security Assessment of Student-Run Capture The Flag Platforms Using CTFd

Research presented at the 2nd JASPER Research Symposium 2026 at LNBTI Japanese IT University, Maharagama. The work examined security risks in a controlled, isolated CTFd test environment.

  • Reviewed security testing scenarios using OWASP Web Security Testing Guide concepts.
  • Explored access control, session handling, JWT-related risks, path traversal, mass assignment, and injection categories.
  • Identified an example API ownership-check issue involving access to user records.
